INTRANEST GUIDE

Set up your IntraNest

Install the server on an intranet PC, connect your browser, then share links, files, and conversation with the team.

1. Start the server

Use Docker Compose or download a standalone release for Windows, macOS, or Linux. Keep the server PC on and allow TCP port 8080 on your intranet firewall.

Server releases · Server repository

2. Find the team access key

After first start, the server creates data/access.token. Share it with teammates using a trusted channel. Anyone with this shared key can manage all shared content.

3. Connect your browser

Open Admin, enter the server address and access key, then choose Check and connect. Chrome may ask the website to access your local network.

Open admin

4. Install the extension

Download the latest release, extract it, and load the folder from chrome://extensions with Developer mode enabled. Open the extension, enter the same server address and key, then connect.

Chrome extension releases

Update the extension

When a newer GitHub release is available, the extension offers Download update or Later. Download the ZIP, open chrome://extensions, remove the old unpacked folder, then load the extracted new folder. Your server address remains in extension storage.

If the connection does not work

Check that the host PC and browser are on the same network, the server is running, the port is open, the address begins with http:// or https://, and the key matches. In Admin, allow Chrome’s local network prompt when it appears. The server must allow the exact web origin in INTRANEST_CORS_ORIGINS.
