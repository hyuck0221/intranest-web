INTRANEST GUIDE

Set up your IntraNest

Three steps to your team workspace. Start with Docker running on an intranet PC.

1. Start the server2. Connect your browser3. Add the extension
01

1. Start the server

Run this command on the server PC with Docker running. Keep the PC on and allow TCP port 43187.

Terminal · macOS / Linux / WSL / Git Bash
curl -fsSL https://github.com/hyuck0221/intranest-server/releases/latest/download/install.sh | sh

Server releases
02

2. Connect your browser

Open the workspace. Enter the server IP or host name and your display name. The port is added automatically.

Server address192.168.1.40
Open workspace
03

3. Add the extension

Download and extract the release. In chrome://extensions, enable Developer mode → Load unpacked → select the extracted folder. Enter the same server address.

Chrome extension releases

Before you start

Docker running. A server PC your team can reach. Chrome for the extension.

Use your team network

There is no sign-in. Anyone who can reach the server can manage its content. Keep port 43187 on a trusted network, off the public internet.

Need help connecting?

Help & updates

Cannot connect?
  • Check that your browser can reach the server PC.
  • Keep Docker and the server running; allow TCP 43187.
  • Enter only the IP address or host name, without a port or path.
  • Allow local network access in browser site settings, then reload.
Update the extension

Download the new ZIP, extract it over the original extension folder, then reload it in chrome://extensions. Keep the folder path to preserve your settings.
