Privacy

IntraNest is designed to keep team content on the server computer you choose.

Updated October 1, 2026

This website

The landing page and guide are static files. They do not collect analytics or send the server address or access key to the project maintainer.

Your browser

Admin saves the server address in this browser’s local storage. The access key remains in the current tab session. The extension stores its configured server and key in Chrome extension storage so it can reconnect. You can remove them from Admin or the extension settings.

Your server

The server stores shared links, chat messages, uploaded files, and the chat-retention setting on its data folder. Chat history is removed after the configured number of days. Your server administrator controls backups and who has the access key.

Release checks

The extension can contact api.github.com to check for a public release. GitHub receives the request and may process its network metadata under GitHub’s own privacy terms. No team content is sent in this request.

Questions

For project questions, use the public GitHub project page.
